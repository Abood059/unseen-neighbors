# The Unseen Neighbors
### An Agent's Quest for the Truth of a World with Hidden Entities

A closed-world AI experiment in which an autonomous agent is placed inside a simulated civilization and asked only one question: **"What is the world?"**

The agent cannot see the inhabitants. It can only interact with them through a file bridge — sending questions and receiving answers from hidden entities. Its goal is to explore, investigate, and attempt to uncover the truth of the world it inhabits.

This project explores epistemic curiosity, meta-awareness, and open-ended exploration in AI agents.
